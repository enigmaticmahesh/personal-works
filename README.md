## 🛠️ Completed

### 📊 Power purchase prediction for UK
This is a task that I got for an interview. A data analytics dashboard that quantifies wind power forecast errors to calculate the risk-adjusted additional non-renewable power procurement needed to balance the UK grid.

*   **⚡ Tech Stack:**
    - Frontend: React, TypeScript, Vite, Tailwind CSS, Shadcn UI
    - Backend: Python 3.13, FastAPI, Uvicorn, Astral uv (Dependency Management)
    - Orchestration: Docker, Nginx (Production Reverse Proxy)
*   **🔗 Project Code:** 
    [Repo](https://gitlab.com/maheshtest87/reint-interview-task)
*   **🔗 Project Preview:** 
    [Preview](https://reint-interview-task-2.onrender.com/)
